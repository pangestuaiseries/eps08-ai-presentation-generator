# 📖 PANDUAN PENGGUNAAN: 1 DETIK BIKIN SLIDE POWERPOINT

Panduan ini menjelaskan cara mengeksekusi kode otomatisasi PowerPoint (VBA) yang di-generate oleh AI.

---

## 🛠️ Langkah-Langkah di Laptop (Windows & Mac)

### Langkah 1: Buka Microsoft PowerPoint
1. Buka aplikasi PowerPoint.
2. Buat presentasi kosong baru (*Blank Presentation*).

### Langkah 2: Buka Jendela VBA Editor
* Tekan tombol pintas keyboard: **`Alt + F11`**  
  *(Jika laptop Anda menggunakan tombol Fn, tekan `Fn + Alt + F11`).*
* Jendela putih abu-abu bernama **Microsoft Visual Basic for Applications** akan terbuka.

### Langkah 3: Buat Module Baru
1. Pada menu bar atas, klik **Insert**.
2. Pilih **Module**.
3. Jendela editor teks kosong akan muncul di tengah layar.

### Langkah 4: Tempel Kode & Jalankan
1. Salin seluruh kode VBA yang dihasilkan dari ChatGPT/Claude (atau ambil dari file `vba-scripts/sample_pitch_deck.vba`).
2. Tempel (*paste*) ke dalam jendela Module.
3. Tekan tombol **`F5`** pada keyboard, atau klik tombol **Play (ikon segitiga hijau)** di toolbar atas.

### Langkah 5: Selesai!
Tutup jendela VBA Editor (`Alt + Q`). Seluruh slide presentasi Anda sudah selesai terbuat rapi di lembar kerja PowerPoint!

---

## 🎨 Tips Mempercantik Slide (1 Klik Desain)
Setelah slide terbuat via script VBA:
1. Klik tab **Design** di PowerPoint.
2. Klik tombol **Designer** di pojok kanan atas (*PowerPoint Designer AI*).
3. PowerPoint akan secara otomatis menyarankan layout visual kelas atas yang menyesuaikan isi teks Anda!
