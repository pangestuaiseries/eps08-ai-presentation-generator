Selamat datang di repositori resmi **Pangestu AI Series — Episode 08**!
Repositori ini berisi seluruh artefak, prompt arsitek presentasi konsultan, script otomatisasi Microsoft PowerPoint (VBA), dan Web Demo Simulator interaktif untuk mengubah outline ide kasar menjadi slide presentasi profesional dalam hitungan detik.

---

## 🎯 Masalah yang Dipecahkan
- **Time Sink**: Menghabiskan 3–4 jam hanya untuk menata kotak, memilih kombinasi warna, dan mengatur hierarki font di PowerPoint.
- **Unstructured Deck**: Slide terlalu padat teks atau tidak memiliki alur cerita yang logis (*Storytelling Arc*).
- **Design Friction**: Kesulitan memulai dari slide putih kosong (*blank canvas anxiety*).

---

## 💡 Solusi: Presentation Architect Framework
Dengan pendekatan ini, Anda **tidak mendesain dari nol**:
1. **Piramida Minto (Pyramid Principle)**: AI menyusun ide Anda menjadi alur *Situation ➡️ Complication ➡️ Resolution*.
2. **Generasi Kode VBA Sekali Klik**: AI menghasilkan script Visual Basic for Applications (VBA) yang kompatibel dengan Microsoft PowerPoint (Windows & Mac).
3. **Eksekusi 1 Detik**: Paste kode ke PowerPoint (`Alt + F11` ➡️ `F5`), dan seluruh struktur slide langsung terbangun otomatis.

## 🚀 Cara Cepat Mulai (3 Langkah)

### Langkah 1: Gunakan Prompt Architect
Buka ChatGPT atau Claude, lalu salin template dari [`PROMPT_PPT_ARCHITECT.md`](PROMPT_PPT_ARCHITECT.md) dan masukkan topik presentasi Anda.

### Langkah 2: Eksekusi di PowerPoint
1. Buka Microsoft PowerPoint baru.
2. Tekan kombinasi tombol **`Alt + F11`** (Membuka jendela VBA Editor).
3. Klik menu **Insert** ➡️ **Module**.
4. Tempel kode VBA yang diberikan AI.
5. Tekan tombol **`F5`** (atau klik ikon tombol Play hijau).
6. Seluruh slide akan langsung terbuat dalam 1 detik!

### Langkah 3: Coba Web Simulator Lokal
Buka file [`app-demo/index.html`](app-demo/index.html) di browser Anda untuk melihat demo interaktif pembuatan slide AI secara visual.
